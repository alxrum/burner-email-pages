Burner Email privacy policy

Last updated: November 18, 2026

Burner Email provides a disposable email address, displays incoming messages, and lets you copy verification codes beside a sign-up form. This policy covers the extension and its welcome, uninstall, and feedback pages.

What the extension collects

The extension has no developer-operated mail server, advertising, analytics, or telemetry. It does not send your browsing history, page contents, or form entries to the developer. It does communicate directly with third-party email providers to create and access disposable mailboxes.

What stays in your browser

chrome.storage.local holds the current disposable address, mailbox access tokens, address history, message headers (including sender, subject, and receipt time), read status, sites where you hid the widget, and local onboarding and rating-prompt settings. Message bodies are not saved in persistent extension storage.

chrome.storage.session holds temporary session state, including the current tab ID, hostname, disposable address, message IDs, and a time-limited verification flow. This allows the code widget to remain available when you move to the next screen on the same site. This state is not sent to the developer. The extension does not use Chrome Sync.

Removing the extension clears its browser storage. It does not delete messages or accounts held by an email provider.

Requests to email providers

Mailboxes are created and read through these API hosts:

  • https://api.mail.tm/* — mailbox creation, authentication, inbox lists, and messages.
  • https://api.tempmail.lol/* — disposable mailbox creation and inbox access.
  • https://api.guerrillamail.com/* — disposable mailbox creation, session access, inbox lists, and messages.

Requests include the disposable address or mailbox identifiers and access credentials needed by the provider. For mail.tm, the extension generates a mailbox password and sends it to that provider; this is not a password from a website you visit. Providers receive your IP address and normal connection metadata. They process and retain mail under their own policies. Requests go directly from your browser to the provider, not through a developer-operated proxy.

Inbox polling runs only while an inbox interface needs updates, with backoff for provider rate limits. There is no continuous background inbox polling after you close the inbox interfaces.

Access to websites and the clipboard

Content scripts run on pages matching http://*/* and https://*/* to find email and verification-code fields and show the Burner widget. The scripts inspect relevant page elements locally. Using the widget can fill a disposable address into an email field and trigger the site's normal input events. The site then receives the address as it would any value you enter. Codes are not automatically filled into verification fields.

When you click Copy, the extension writes the selected address or code to your clipboard. It does not read your existing clipboard contents.

Permissions, explained

  • storage — saves disposable mailbox access, address history, message headers, hidden-site preferences, and temporary session state in your browser.
  • host_permissions for the three API hosts listed above — allow direct requests to the mail providers.
  • content_scripts.matches for http://*/* and https://*/* — allow the widget to appear on sign-up pages across websites. This does not add website hosts to the extension's API host permissions.

Pages the extension opens

After installation, the extension opens a welcome page. After removal, Chrome opens an uninstall page. If you choose to provide feedback from the rating prompt, it opens the feedback page; if you choose to leave a store review, it opens Chrome Web Store. The welcome, uninstall, and feedback pages are ordinary websites hosted on GitHub Pages.

Those three service pages use Umami web analytics at cloud.umami.is to measure page visits. These analytics run on the service pages, not inside the extension. They are separate from your disposable mailbox. Hosting and analytics services process connection metadata according to their own policies. The privacy policy page does not include that analytics script.

Feedback you choose to submit

The uninstall form sends your selected removal reason and optional comment to Google Forms. The feedback form sends only your comment. Neither form asks for your email address, and the pages do not attach your disposable address, mailbox credentials, message contents, or a user ID. Google processes form submissions and connection metadata under its own policies. Please do not submit passwords, verification codes, or private messages.

Disposable mail is not private storage

Use these mailboxes only for throwaway sign-ups. Do not use them for important accounts, account recovery, or sensitive information. Access and retention depend on the provider. Mailbox availability and a specific lifetime are not guaranteed.
