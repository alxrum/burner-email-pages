# Burner Email pages

Static welcome, uninstall, and feedback pages for Burner Email.

- `welcome/`: installation confirmation and pinning instructions.
- `uninstall/`: removal reason and optional comment.
- `feedback/`: one comment field; no email or store-review link.
- `privacy/`: https://alxrum.github.io/burner-email-pages/privacy/ (same repository, no analytics).

All three pages include the shared Umami page-analytics script. The extension itself contains no analytics.

This is a local build. Google Forms IDs are intentionally empty until the separate publication/setup step; an unconnected form clearly says nothing was sent.
